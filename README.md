# Gadbox_DW
Project Tubes Desain Web 
Apa itu Gadbox??
Gadbox merupakan sebuah website e-commerce yang berfokus pada penjualan smartphone atau handphone. Website ini dirancang untuk memudahkan pengguna dalam melihat berbagai pilihan HP, mengetahui informasi pada produk, dan melakukan pembelian secara online. Project ini dikembangkan sebagai tugas kelompok dengan menerapkan teknologi pengembangan web. Project ini dikembangkan oleh kelompok Hayuk.
